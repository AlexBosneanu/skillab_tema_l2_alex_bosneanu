Faza A Înregistrarea tool-urilor  (o singură dată, automat la import tools)
tools/__init__.py
import basic_tools
Importul rulează decoratorii din modul → umple registry-ul.
tools/basic_tools.py
@register_tool · calculator / get_datetime / web_search
Fiecare funcție-tool e decorată. Parametrii vin din params_models.py (Pydantic).
tools/registry.py
register_tool(func)
Validează (1 param BaseModel + docstring ≥ 15) și scrie în dict.
TOOL_REGISTRY
{ "calculator": {...}, "get_datetime": {...}, "web_search": {...} }
Dict global cu func + params_model + description. Folosit mai târziu de catalog() și call().

agent.py
